# Informaci-n-e-Investigaci-n-Portuaria
Análisis financiero y operacional de los principales terminales portuarios del Perú. Consolida estados financieros, indicadores clave de rentabilidad (ROA, ROE, EBITDA), liquidez, solvencia y desempeño operativo en un dashboard interactivo. Adicionalmente de una propuesta de modelado financiero de cada puerto.
